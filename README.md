# Injection Technique – Manuale online

Manuale DENTAG ITALIA: come creare in exocad il modello anatomico e il modello ridotto per le mascherine della injection technique.

## Struttura

- `index.html` – il manuale (pagina unica con capitoli)
- `img/` – le 10 schermate
- `.nojekyll` – fa pubblicare i file così come sono

## Pubblicazione su GitHub Pages

1. Creare un nuovo repository, ad esempio `injection-technique-manual`.
2. Caricare tutto il contenuto di questa cartella nella radice del repository.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, cartella `/ (root)`.
4. Il manuale sarà online su `https://lukasamplatz.github.io/<nome-repository>/`.
